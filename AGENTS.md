# Конвенции проекта

Читается и людьми, и агентами (Claude Code, Codex). Прежде чем писать код —
прочти [README](README.md), а если работаешь над визуализацией —
[docs/3d-roadmap.md](docs/3d-roadmap.md).

## Главное правило

**Числа считает движок, языковая модель их только объясняет.** Это требование
технического задания, а не стилистика. Никогда не проси модель посчитать балл,
сравнить сценарии или прикинуть эффект: для этого есть `lib/engine/`. Модель
получает готовый `ScenarioBreakdown` и пересказывает его словами.

Если модели нужна величина, которой нет в `ScenarioBreakdown`, — добавь её в
движок и покрой тестом, а не поручай вычисление модели.

## Слои

| Папка | Что там | Можно ли менять |
|---|---|---|
| `lib/domain/` | данные из ТЗ: районы, показатели, 14 мероприятий, правила, события | только по согласованию: числа взяты из ТЗ дословно |
| `lib/engine/` | валидатор, формула Score, атрибуция по Шепли, полный перебор | менять осторожно, тесты прибивают эталонные значения |
| `lib/ai/` | мультипровайдерный клиент, объяснение, агент с инструментами | да |
| `components/sim/` | интерфейс симулятора | да |
| `components/city/` | 3D-карта | да |
| `app/` | страницы и маршруты API | да |

## Команды

```bash
pnpm dev      # разработка, работает без переменных окружения
pnpm test     # 12 тестов движка на node:test через tsx
pnpm lint
pnpm build
```

CI гоняет `lint`, `test` и `build` на каждый push и pull request. Ветка с красным
CI не вливается.

## Стиль

- Комментарии и весь текст интерфейса — по-русски. Комментарий объясняет **почему**
  так сделано, а не пересказывает код.
- Никаких `any`, никаких `@ts-ignore`. Строгий TypeScript включён.
- Данные, пришедшие снаружи (тело запроса, адрес страницы, ответ модели), проходят
  через Zod. Схемы лежат в `lib/ai/schema.ts`.
- Чистая логика живёт в `lib/` и покрывается тестами. Компоненты не считают —
  они показывают.
- ИИ-функции обязаны деградировать: без ключа и при любой ошибке модели продукт
  продолжает работать на детерминированном расчёте. Смотри три шлюза в
  `lib/ai/explain.ts`.
- Никаких `Math.random` в отрисовке: картинка должна быть воспроизводимой.

## Работа вдвоём

Чтобы не сталкиваться в merge, договорились о зонах:

- визуализация — `components/city/**`, `public/models/**`, `docs/3d-roadmap.md`;
- движок, ИИ и интерфейс симулятора — `lib/**`, `components/sim/**`, `app/**`.

Ветки от `main`, имя вида `feat/city-walk-mode`. Перед пушем — `pnpm lint && pnpm test && pnpm build`.
